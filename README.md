# JonMir ♡

A simple personal website for **JonMir**, made with Flask.

## Pages

- A first, private project
- JonMir Life
- JonMir Memories
- JonMir Backups
- JonMir Mashups

## Built With

- HTML
- CSS
- Python
- Flask

## Run

Install Flask:

    pip install flask

Run the website:

    python app.py

Then open:

    http://127.0.0.1:5000
